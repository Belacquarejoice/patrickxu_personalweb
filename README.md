# Patrick Xu · Personal Website（模板基底）

纯 HTML / CSS / JS，不需要安装任何东西。双击 `index.html` 就能打开（字体和 P2 的等高线库 d3-contour 需要联网加载）。

## 文件结构

```
index.html              页面骨架（7 个 section）+ 拓印滤镜
assets/js/content.js    ★ 所有内容都在这里改（文字、图片路径、位置）
assets/js/main.js       把内容渲染成页面 + 交互 + 编辑模式
assets/css/style.css    全部样式。最上面是色板 / 字体 / 圆角等变量
assets/img/             图片放这里。paper.svg 是纸张质感
```

## 七页

| 页 | id | 形式 | 改内容 |
|---|---|---|---|
| P1 | hero | 半调球体 + 条纹块 + 小图标，名字标签居中 | `hero` |
| P2 | explore | 3D 等高线地图，5 段经历用折线连成路线 | `explore.items` |
| P3 | influence | 文件夹堆，悬停看单条视频和数据 | `influence.files` |
| P4 | create | 可旋转线框球，8 个图片位，点开在右侧看详情 | `create.items` |
| P5 | climb | 几何攀岩墙，悬停岩点出图 / 视频 | `climb.holds` |
| P6 | vibe | 三栏撕纸拼贴，每栏 5 张 4:5 照片，原图彩色 | `vibe.columns` |
| P7 | contact | 黑色铭牌 + 小号半调球体 + 小图标 | `contact` |

## 常见操作

- **改文字**：在 `content.js` 里改引号中的内容。
- **标题下的一句说明**：P2 到 P6 每页的 `lede` 字段。删掉这个字段，那一页就不显示说明。
- **加一条经历 / 一个文件夹 / 一件作品 / 一个岩点**：复制数组里的一个 `{ ... }` 粘贴在后面，改内容。页面会自动排版（球面会自动重新排布）。
- **换图**：把图片放进 `assets/img/`，在对应字段写 `"assets/img/文件名.jpg"`。字段留空 `""` 会显示占位框。
- **攀岩视频**：`media.src` 填 `.mp4` / `.webm`，悬停时才加载并静音循环播放。`assets/img/` 里的是网页压缩版（540×960、H.264、30fps、无音轨，HDR 已转成普通色彩），原片在 `Desktop/photo`。新加的手机视频也要先压缩再放进来，否则单个就有几十 MB。
- **P2 地图**：`seed` 换个数字就生成一张新地形；每段经历的 `at` 是地图上的点，`card` 是卡片左上角位置（都是百分比）。
- **P6 拼贴**：`x / y / w` 是栏宽的百分比，照片高度按 4:5 自动算；横版照片可加 `ar: "5 / 4"`。
- **P5 岩点**：用 `x / y`（百分比）和 `s`（大小）控制。
- **P3 数据**：每条视频的 `stats` 里填播放、点赞、评论、转发、收藏。留空的项（包括 `date`、`text`）页面上直接不显示，编辑模式下才会出现，方便补填。截图按原比例完整显示，不裁切。
- **P2 logo 大小**：方形或细长的 logo 可以加 `logoH: 44` 调高度。
- **P4 球体**：拖动旋转，点图片在右侧看详情；`hint` 是球下方的提示文字。球面上每张图的面板按图片比例自动定形状（面积差不多），不裁切；右侧大图也按原比例完整显示，太高时整张缩进框内，两侧露出网站底色。`link` 留空时不显示链接按钮。截图自带的白边 / 黑边要先裁掉再放进来。
- **P1 图形**：在 `main.js` 的 `heroArt()` 里，坐标都写在一处，改数字就能挪位置。

## 编辑模式（浏览器里直接改）

1. 点导航右上角 **Edit**（或按 `Shift + E`）。
2. 青色虚线框的文字可以直接点进去改；橙色虚线框是图片位，点击可选本地图片预览。
3. 改动会先存在浏览器里（刷新不丢）。点 **导出 content.js** 下载新文件，覆盖 `assets/js/content.js` 才算真正保存。
4. 换图时，**一定要把那张图片 / 视频也复制进 `assets/img/`**，否则刷新后会显示不出来（工具条会提醒；页面上会显示 “File not found” 和缺的文件名）。
5. 上线前把 `content.js` 里的 `showEditButton` 改成 `false`，访客就看不到 Edit 按钮。

> 导出的 content.js 不带注释，字段说明以本文件为准。

> 改完 css / js 后，把 `index.html` 里三处 `?v=` 后面的数字加 1，浏览器就不会继续用缓存里的旧文件。

## 设计规则（改样式时保持一致）

- 颜色只用 `style.css` 顶部 6 个变量：`--paper` `--paper-hi` `--ink` `--teal` `--orange` `--mint`。P5 岩点不受限制。
- 全部直角（`--r: 0`），描边只有 `--line`，只用硬投影，不用柔和阴影。
- 标题 Geist（黑体），正文 IBM Plex Mono（打字机体）。
- 加 `class="stamp"` 的图形会带拓印质感。
- P2 卡片和 P4 球面上的照片默认黑白（悬停 / 选中时恢复彩色）；P6 是原图彩色。
- logo 来源：UNIQLO（Simple Icons）、Publicis / ByteDance（Wikipedia 条目里的 logo 文件）、闻献（从你给的图里抠出）。
- 动画：所有过渡都用 `--dur`，现在是 `0ms`。之后加动画时，从这里开始。
